## Breaking changes

`CloudGoogle` and `GCPCredentials` are no longer exported from the `libs.dlt`
package root. This keeps the optional GCP filesystem dependency behind its
dedicated adapter boundary.

Update downstream imports from:

```python
from libs.dlt import CloudGoogle, GCPCredentials
```

to:

```python
from libs.dlt.filesystem_gcp import CloudGoogle, GCPCredentials
```

The bucket naming helpers and `DestinationType` remain available from
`libs.dlt`. `src.edge` continues to expose the GCP helpers for orchestration
callers.
